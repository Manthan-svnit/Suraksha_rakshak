# Suraksha Rakshak 🛡️

**Suraksha Rakshak** is a modern web application built to enhance safety and security monitoring through machine learning model integration. Deployed live on Vercel, this project provides real-time detection and classification across multiple safety categories.

🚀 **Live Demo:** [suraksha-rakshak.vercel.app](https://suraksha-rakshak.vercel.app)

---

## 🌟 Key Features

- **Multi-Class ML Model:** Integrates a custom-trained model supporting multi-class safety detection.
- **Fast & Responsive UI:** Built with Vite and modern JavaScript/TypeScript for minimal load times and optimal user experience.
- **Seamless Deployment:** Continuous deployment powered by Vercel.

---

## 🛠️ Tech Stack

- **Frontend:** React / JavaScript / TypeScript
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Machine Learning:** Integrated multi-class classification model

💻 Getting Started Locally
Prerequisites
Ensure you have the following installed on your system:

Node.js (v16 or higher)

npm or yarn

Installation
Clone the repository:

Bash
git clone [https://github.com/Manthan-svnit/Suraksha_rakshak.git](https://github.com/Manthan-svnit/Suraksha_rakshak.git)
cd Suraksha_rakshak
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Build for production:

Bash
npm run build
